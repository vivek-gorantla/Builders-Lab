# 04 - URL Shortener & Analytics Service

## What You Are Building
A Bitly-style URL shortener backend with DB persistence (SQLite/Postgres), Base62 slug encoding, TTL expiration, and click analytics tracking.

## What You Will Learn
- Base62 encoding algorithms
- Database persistence for high-read redirect systems
- Analytics logging & click telemetry
