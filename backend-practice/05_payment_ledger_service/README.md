# 05 - Fintech Double-Entry Payment Ledger

## What You Are Building
A double-entry financial ledger service enforcing zero-balance accounting principles ($\sum 	ext{debits} = \sum 	ext{credits}$), balance checks, and idempotent reference locks.

## What You Will Learn

- Atomic database transactions for money transfers
- Global ledger audit verification algorithms
