# 07 - OAuth2 / JWT Auth & Session Service

## What You Are Building
A production-ready user authentication service supporting salted password hashing, JWT access/refresh token generation, database token blacklisting, and session validation.

## What You Will Learn
- Salted password hashing (`pbkdf2_hmac`)
- JWT Access & Refresh Token Lifecycles
- Database token revocation / blacklisting
