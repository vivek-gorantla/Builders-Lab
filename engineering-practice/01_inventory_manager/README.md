# 01 - Inventory Manager

## What You Are Building
An in-memory store inventory management component that tracks products, handles stock increments/decrements, detects low-stock items, and outputs aggregate inventory metrics.

## What You Will Learn
- Object-Oriented Programming (OOP) in Python
- State management using dictionaries
- Input validation and exception handling (`ValueError`, `KeyError`)
- Designing clean object interfaces

## Requirements
- Complete the methods stubbed out in `solution.py`.
- Ensure all business rules and validation checks are satisfied.
- Ensure all tests pass.

## Getting Started
Open `solution.py` and replace `raise NotImplementedError` statements with your implementation.

## Testing
Run the test suite from this directory or root:
```bash
python -m pytest
```
