# 03 - Job Queue

## What You Are Building
An in-memory producer-consumer job queue using worker threads to execute asynchronous jobs safely while tracking execution status.

## What You Will Learn
- Python `threading` and `queue.Queue`
- Thread safety and state synchronization
- Clean thread shutdown mechanisms
- Robust exception handling in worker loops

## Requirements
- Complete `JobQueue` in `solution.py`.
- Pass all pytest tests in `tests/test_solution.py`.

## Getting Started
Open `solution.py` and implement the stubbed methods.

## Testing
Run:
```bash
python -m pytest
```
