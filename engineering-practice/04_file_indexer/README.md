# 04 - File Indexer

## What You Are Building
A local directory scanner and file metadata indexer supporting filename substring search, extension filtering, largest file detection, and disk usage statistics.

## What You Will Learn
- File system traversal with Python `pathlib`
- Extracting file stat metadata (`size`, `mtime`)
- Data aggregation and sorting
- Graceful exception handling for unreadable folders

## Requirements
- Complete `FileIndexer` in `solution.py`.
- Run pytest to verify behavior.

## Getting Started
Edit `solution.py` and fill in the methods.

## Testing
Run:
```bash
python -m pytest
```
