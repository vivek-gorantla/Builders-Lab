# Submission Guide - Project 04: File Indexer

Before submitting, check:
- [ ] Recursively scans directories using `pathlib`.
- [ ] Extension filtering handles both `.ext` and `ext`.
- [ ] `search_by_name` performs case-insensitive search.
- [ ] `find_largest_files` correctly sorts by size descending.
- [ ] Invalid directory paths raise `FileNotFoundError`.
- [ ] Tests pass.

## Evaluation Criteria
- **Functional Correctness**: 50 points
- **FileSystem Traversal & Exception Handling**: 20 points
- **Filtering & Aggregation**: 10 points
- **Code Quality**: 10 points
- **Performance**: 10 points

**Total**: 100 points
