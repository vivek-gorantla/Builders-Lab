# 05 - Log Processing Service

## What You Are Building
A streaming log analyzer component capable of parsing structured application logs, calculating status distribution metrics, and identifying top users and endpoints.

## What You Will Learn
- Memory-efficient file streaming in Python
- String parsing and regex / split operations
- Data aggregation using dictionaries / counters
- Defensive parsing against corrupted log inputs

## Requirements
- Implement `LogAnalyzer` in `solution.py`.
- Ensure streaming iteration is used for file reading.
- Pass pytest suite.

## Getting Started
Open `solution.py` and replace stub implementations.

## Testing
Run:
```bash
python -m pytest
```
