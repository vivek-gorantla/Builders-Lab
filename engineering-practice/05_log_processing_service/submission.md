# Submission Guide - Project 05: Log Processing Service

Before submitting:
- [ ] `parse_line` handles valid and malformed lines correctly.
- [ ] Files are processed using line-by-line streaming.
- [ ] Top endpoints and top users are correctly aggregated and sorted.
- [ ] Missing files raise `FileNotFoundError`.
- [ ] Tests pass.

## Evaluation Criteria
- **Functional Correctness**: 50 points
- **File Streaming & Memory Efficiency**: 20 points
- **Malformed Input Handling**: 10 points
- **Code Quality**: 10 points
- **Performance**: 10 points

**Total**: 100 points
