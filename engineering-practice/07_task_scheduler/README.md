# 07 - Task Scheduler

## What You Are Building
An in-memory priority-queue task scheduler that executes callables at designated future timestamps using background thread dispatch.

## What You Will Learn
- Priority queue management with `heapq`
- Thread synchronization and timed wait loops
- Datetime and epoch timestamp conversions
- Graceful lifecycle management (`start`, `stop`)

## Requirements
- Complete `TaskScheduler` in `solution.py`.
- Pass all unit tests in `tests/test_solution.py`.

## Getting Started
Open `solution.py` and replace stub implementations.

## Testing
Run:
```bash
python -m pytest
```
