# Submission Guide - Project 07: Task Scheduler

Before submitting:
- [ ] Tasks ordered by timestamp in priority queue (`heapq`).
- [ ] Duplicate task IDs raise `ValueError`.
- [ ] Cancelled tasks are skipped upon trigger time.
- [ ] Exception handling catches failing tasks and sets status to FAILED.
- [ ] Scheduler thread stops cleanly.
- [ ] Tests pass.

## Evaluation Criteria
- **Functional Correctness**: 50 points
- **Priority Queue & Concurrency**: 20 points
- **Error Handling**: 10 points
- **Code Quality**: 10 points
- **Performance**: 10 points

**Total**: 100 points
