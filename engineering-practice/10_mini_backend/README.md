# 10 - Mini Backend

## What You Are Building
A domain-driven backend service layer for a task management application with user registration, ownership access control, status state transitions, and paginated search.

## What You Will Learn
- Service layer architecture and separation of concerns
- Entity data modeling (`User`, `Task`)
- Access control & ownership authorization checks (`PermissionError`)
- Structured response formats and pagination mathematics

## Requirements
- Implement `User`, `Task`, `UserService`, and `TaskService` in `solution.py`.
- Pass all unit tests in `tests/test_solution.py`.

## Getting Started
Open `solution.py` and implement the stubbed classes/methods.

## Testing
Run:
```bash
python -m pytest
```
